# Gastro-Kasse – Download

Windows-Installer für die Hauptkasse (Kassen-PC).

## Herunterladen

👉 **[Neueste Version herunterladen](https://github.com/sedatReis/gastro-kasse-download/releases/latest)** → unten bei „Assets“ die Datei `Gastro-Kasse.Setup.x.y.z.exe`.

## Installieren

1. Die `.exe` starten.
2. Windows warnt beim ersten Mal („Der Computer wurde durch Windows geschützt“), weil der Installer nicht signiert ist:
   **Weitere Informationen → Trotzdem ausführen**.
3. Danach „Gastro-Kasse“ über das Desktop-Symbol starten.
4. Windows-Firewall: **Zugriff zulassen** (privates Netzwerk) – sonst erreichen die Kellner-Handys die Kasse nicht.

Daten und Einstellungen liegen in `%APPDATA%\Gastro-Kasse` und bleiben bei Updates erhalten.
Für ein Update einfach die neue Version herunterladen und darüber installieren.
